# Skills instaladas

Skills de diseño/animación de Emil Kowalski (https://github.com/emilkowalski/skills),
licencia MIT (ver `LICENSE-emilkowalski-skills`). Se instalaron solo las aplicables a un
proyecto web (Next.js); se excluyeron `animate-expo` y `write-swift` porque son para
React Native/Expo y Swift respectivamente, que este proyecto no usa.

- `animate` — construir animaciones desde cero.
- `animation-vocabulary` — glosario inverso para nombrar un efecto de motion.
- `apple-design` — diseño e interacción estilo Apple llevado a la web.
- `ask-sonner` — guía de la librería de toasts Sonner.
- `emil-design-eng` — filosofía general de pulido de UI y component design.
- `find-animation-opportunities` — detecta dónde falta animación en la UI.
- `improve-animations` — auditoría y plan de mejora del motion de todo el proyecto.
- `mobile-native` — que la web se sienta nativa en móvil (safe areas, tap, scroll, etc.).
- `pick-ui-library` — elegir la librería correcta para una tarea de frontend.
- `prototype` — construir varias variantes de una pieza de UI para comparar.
- `review-animations` — revisar animaciones existentes contra un estándar alto.

Se invocan automáticamente cuando el pedido encaja con su descripción, o a mano con
`/animate`, `/review-animations`, etc.
